# Release Notes

## 0.1.3 - 2026-02-14

- Playwright launch options now accept `executable_path` and `args` via `playwright_config`, enabling use of a custom Chromium binary without the bundled Playwright download.
- CLI docs now describe `--playwright-config-file` and include an example for custom executables.
- Python usage docs now include a `playwright_config` example with `executable_path` and `args`.
